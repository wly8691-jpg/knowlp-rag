## 六、增补⑤：历史对政策 —— 选 b（低风险）

**选择：b —— 历史 202（现 209）对不入负侧，暂作冷启动先验。**

依据：
1. **前置条件不可验证**：弱负样本的成立条件是「前列被忽略」（rank ≤ 5），全档 0 个位置字段，无法证明任何一个历史 ignored 边在前列。把不可验证的负样本喂给 BT-MLE 是直接教错方向。

3. **a 的收益可以事后补**：弱对通路点着以后，新数据带 rank 持续进 buffer；历史对若将来需要，随时可以按当时的存活过滤再议——现在是单向门，不急于推开。
4. **落实**：`preference_buffer.pair_edges` 弱对分支要求 `rank ≤ 5`（`FRONT_RANK_MAX`）且**必须存在** rank 字段——历史行自动全部落空，政策 b 由代码结构保证，不靠纪律。
