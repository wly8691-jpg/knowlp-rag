# 网页方案借鉴工作流 — KnowLP 操作手册

> 用途：把别人的公开方案（网页/论文/竞品页面）消化进知识库，结合企业介绍，产出自己的类似方案。
> 日期：2026-08-05 ｜ 状态：流程就位，待实操验证

## 核心认知

KnowLP 不只是检索工具，是**消化 → 建图 → 检索 → 生成**闭环：
网页/PDF/URL → ingest 消化 → 双图知识图谱 → 检索 → 结合新输入 → 出方案

## 前置条件（已就位）

- KnowLP 引擎：`Obsidian Vault/系统/knowlp-graph/`（unified_search.py、ingest 管线）
- ingest 管线：`Obsidian Vault/系统/ingest-pipeline/ingest.py`（支持 URL 和本地文件）
- Obsidian 插件：dataview / local-rest-api / templater（Web Clipper 未装，不需要）

## 标准流程（四步）

### ① 丢 URL 进消化管线

```bash
# 单个网页
python "C:/Users/wly10/Documents/Obsidian Vault/系统/ingest-pipeline/ingest.py" <网页URL>

# 指定消化角度（推荐）
python "...ingest.py" <URL> -q "重点关注方案架构和实现细节"

# 本地文件（PDF/DOCX/MD）
python "...ingest.py" <文件路径>

# 批量
python "...ingest.py" raw/
```

管线自动做：格式转换 → 语义分块 → 逐块摘要 → KnowLP 检索 → wiki 页生成 → 写入 `wiki/`

### ② 输入企业介绍

- 文字：直接粘贴给 Hermes
- 文件：丢进 raw/ 或直接给路径
- 链接：ingest 消化

### ③ Hermes 结合产出方案

给 Hermes 的指令模板：
> "用 vault 里刚消化的 [方案A] + 这份 [企业B] 介绍，出一个类似的方案：
> ① 方案A 的架构/核心逻辑拆解
> ② 针对企业B 的本地化差异点（资源/行业/规模）
> ③ 落地步骤"

### ④ 产出归档

- 方案 → `wiki/` 或项目目录
- 借鉴笔记 → 相关 docs/（参照 `docs/zero-mem-借鉴.md` 格式）

## 变体玩法

| 场景 | 做法 |
|---|---|
| 竞品页面拆解 | ingest URL → 出架构分析 → 你自己的版本 |
| 论文吸收 | ingest arXiv → 拆解笔记（Zero-Mem 实战已验证） |
| 方案库复利 | 多次消化后，unified_search 跨案例检索，新方案自动带历史参考 |
| 剪藏兜底 | 浏览器手动存 → 丢进 raw/ → ingest 批量消化 |

## 边界（重要）

- ✅ 公开资料：论文/开源/公开网页/研报 —— 随便消化
- ❌ 私有/付费/内部/NDA 内容 —— 不进 vault（红线）
- ⚠️ 开源代码复用要保留版权声明；论文引用注明出处
