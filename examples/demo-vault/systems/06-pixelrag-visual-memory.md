PixelRAG 解决跨机视觉记忆检索：另一台机器上的截图、图表、白板照片，被视觉索引之后在本机可查。

## 解决什么问题

文本检索永远够不着「只存在于图片里」的记忆：架构图上的一根连线、白板角落的一个前提条件、截图里的报错原文。PixelRAG 把这些视觉资料变成可检索的视觉记忆。

## 依赖与边界

- 概念上依赖 [[02-vector-search]] 的嵌入思想，但对象是图像
- 需要 GPU 环境（视觉模型较重），本机无 GPU 时其余引擎不受影响
- 远端结果要标注来源机器，不伪装成本地笔记

## 什么时候用

- 明确记得「看过一张图」但笔记里没有文字记录
- 跨机协作：台式机索引，笔记本查询
